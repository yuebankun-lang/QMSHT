# 清明上河图 · 虹桥 — 视频定格 AR

流程：扫虹桥图 → 画动起来（8.5 秒视频）→ 播完定格成一张图 → 点画上发光的圆点（虹桥／大船过桥／桥头市集）→ 弹出介绍卡，同时播这一处的解说。

## 文件清单

| 文件 | 是什么 |
|---|---|
| `index.html` | 主页面，全部代码都在这一个文件里，用 VS Code 打开改它 |
| `targets.mind` | 识别文件（虹桥图编译的，不要动） |
| `hongqiao_target.jpg` | 识别图原件，要扫的就是这张；打印请用这张原文件、哑光纸 |
| `intro_video.mp4` | 满画幅版视频 v2，8.5 秒 |
| `freeze_frame.jpg` | 视频最后一帧截图，定格时显示它，所以切换不跳 |
| `audio/narration_bridge.mp3` | 虹桥解说，约 25 秒 |
| `audio/narration_ship.mp3` | 大船过桥解说，约 23 秒 |
| `audio/narration_market.mp3` | 桥头市集解说，约 21 秒 |
| `archive/` | 旧版带手机框视频的尾帧，留档，不参与运行 |

解说为标准普通话、沉稳男声、语速放慢；卡片上的文字与解说词是同一份。

## 怎么测

1. 用 VS Code 打开这个文件夹，对 `index.html` 开 Live Server，先在电脑浏览器看开始界面和按钮是否正常（电脑没摄像头，AR 本身测不了）。
2. 真机测试要用 iPhone + HTTPS 地址：把整个文件夹传到一个 HTTPS 托管（或做端口转发），用 iPhone 打开链接。
3. 点「开始体验」→ 允许摄像头 → 对准打印出来的虹桥图（哑光、贴平，让画占手机画面六成以上）。
4. 依次验四件事：能认出图、视频能播、播完能定格且热点出现、点热点能出卡片和解说。
5. 中途把手机移开再移回来，验一遍：视频会暂停、卡片会收起，重新扫到后接着原来的进度，不从头来。

## 已知口径

- 视频是 16:9、原图约 1.56:1，比例不同，所以视频层按「高」与识别图对齐（宽 1.147 × 高 0.641），是浮在画上的一层，不硬求与印刷画完全重合，也没有拉伸变形。
- 定格图就是视频最后一帧，热点坐标按这张图量的：虹桥 (0.057, 0.090)、大船 (0.367, -0.051)、市集 (-0.459, -0.077)。换视频或换定格图，要重新量这三个点。
- 画面中央那条篷船是生成视频补出来的，没有给它设热点，介绍里也不要把它当原图细节讲。
- 视频自带一小段环境声；若手机拦了带声音播放，代码会退回静音播放，画面不受影响，点热点时解说仍会响（开始时已做过声音解锁）。
